## GET /users/{id}

Returns one user.

- **Path parameters:** `id` (string, required): the user's ID.
- **Request body:** none.
- **Success response:** `200 OK` with the user object.
- **Errors:** `404 Not Found` if no user has this ID.

## POST /users

Creates a user.

- **Path parameters:** none.
- **Request body:** JSON user object (required).
- **Success response:** `201 Created` with the new user object.
- **Errors:** `400 Bad Request` if the body is missing or invalid.

## DELETE /users/{id}

Deletes one user.

- **Path parameters:** `id` (string, required): the user's ID.
- **Request body:** none.
- **Success response:** `204 No Content`.
- **Errors:** `404 Not Found` if no user has this ID.
